This repository contains the code related to the article "Learning solutions of parameterized stiff ODEs using Gaussian processes" written by I. Cortes Garcia, P. Förster, W. Schilders and S. Schöps.

### Reproducing the results
The code is written in [Julia](https://julialang.org) and set up as a [Julia package](https://julialang.org/contribute/developing_package). All data required for the plots and tables presented in the article is collected in the `csv` directory. The data for Figure 8 can e.g. be found under `csv/vdpo/doe/`. The data can also be reproduced by running the appropriate script however, in this case e.g. `example_vdpo.jl`. (The `vdpo` in the filename matches the shorthand VDPO for the van der Pol oscillator from the article and the same also holds for the other examples.) Running a script can e.g. be achieved by opening a Julia REPL and executing `include("example_vdpo.jl")`. The first time any of the scripts is run, Julia will gather the package dependencies and install/precompile them, which may take some time, depending on your current system. The scripts also suffice to reproduce the results presented in the supplementary materials.

Before running a script, one needs to uncomment the line containing the experiment of interest. This is to avoid running all experiments back to back, as this may take a long time. To ease the process of finding the code for a particular result of interest, the example scripts all follow the same structure. At the very top, the code for computing the max-to-mean ratios is provided. Scrolling down, one always finds a function definition first, before a number of commented out calls to that function. Staying with `example_vdpo.jl` as an example, we e.g. first find a definition for `vdpo_conventional_doe()`, followed by calls to this function with the appropriate arguments to reproduce the data as saved in `csv/vdpo/doe/`.

### Note on plotting
The code uses the [Plots](https://docs.juliaplots.org/stable) package for plotting, which provides a number of backends. The default choice in the scripts is `unicodeplots`, which directly plots in the command line. For more interactive plots, one can simply comment out the line `unicodeplots()` at the top of the respective script and uncomment the `plotly()` directly below. The plots are then created as HTML files and can be interacted with in your default browser.

### GP implementation and reparameterizations
The `src` directory contains the actual GP implementation, providing all necessary functionality for the experiments, including the code for solving the examples, which is e.g. provided in `src/ExampleODEs.jl`. The implementation of the reparameterizations can be found in `src/Reparameterization.jl`, with the core part being located in the function `reparameterize()`.
